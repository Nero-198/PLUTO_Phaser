# 反対チャネル180°固定 相対位相実測

測定日: 2026-07-28

## 測定方法

各周波数で次の2方向を実測した。

1. 両チャネルを0°に設定し、Rx1/Rx2間の基準相対位相を2回取得
2. CH2を180°に固定し、CH1を0～337.5°まで22.5°刻みで掃引
3. CH1を180°に固定し、CH2を同様に掃引

各掃引状態は2回取得した。期待する相対位相は次のように定義した。

```text
期待相対位相 = wrap(固定チャネル設定 - 掃引チャネル設定)
位相誤差 = wrap(両チャネル0°からの測定相対位相 - 期待相対位相)
```

したがって、掃引チャネルも180°にした状態では期待相対位相が0°になる。

対象周波数は2.3、2.4、2.5、2.7、3.0、3.3、3.5、3.8 GHz。Plutoの設定は前回と同じく、Tx gain -20 dB、Rx gain 30 dB、1 MHz複素トーン、8 MS/s、1キャプチャ16,384 samples、基板ATT 0 dB、LNA両方ONとした。

## 前回の後処理結果との比較

前回は、反対チャネルを0°にした測定結果から各チャネルの180°状態を数学的に差し引いた。今回の直接測定と、その後処理から予測した値との差のRMSは1.49°だった。

特に2.3 GHz CH2の90°設定は、前回の予測が絶対値10.47°、今回の直接測定が10.03°であり、大きな誤差が再現した。

最大残差は3.0 GHz、CH2、337.5°設定の4.11°だった。測定時刻、再設定、温度、両チャネル0°基準の再取得による変動を含むため、校正テーブルを作る場合は反復回数を増やす必要がある。
